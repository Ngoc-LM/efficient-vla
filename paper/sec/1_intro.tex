\section{Introduction}
\label{sec:intro}

VLA policies map images, a language instruction and the robot state to actions through a pretrained vision-language model (VLM) and an action head~\cite{black2024pi_0,shukor2025smolvla}.
At batch size one inside a control loop, every re-plan waits for the full model.
Efficient-VLA work cuts this cost in the model, the decoding, the execution or the runtime (\cref{sec:study}), but a saving can change closed-loop behaviour: an ONNX export of this SmolVLA checkpoint cut median latency by 40\% and, through truncated instructions, success from 70\% to 41\%~\cite{islam2026faster}.

This report studies SmolVLA~\cite{shukor2025smolvla} on LIBERO-Spatial~\cite{liu2023libero} with a Tesla T4, a GPU without bfloat16 tensor cores, without training: weights and protocol stay fixed, only the execution changes.
It surveys efficient VLAs and diffusion versus flow matching (\cref{sec:study}; 10-paper literature matrix), reproduces the released checkpoint (\cref{sec:reproduce}), analyses it (\cref{sec:analysis}), and tests on identical episodes whether to re-plan less often or more cheaply (\cref{sec:improve}).
The levers that make re-planning cheaper are known~\cite{ma2025running,tang2026fewer}; the contribution is a measured account of why each helps on this hardware and a paired closed-loop test of whether success is preserved.
