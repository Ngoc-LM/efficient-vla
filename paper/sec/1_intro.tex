\section{Introduction}
\label{sec:intro}

VLA policies map images, a language instruction and the robot state to actions through a pretrained vision-language model (VLM) and an action head~\cite{black2024pi0,shukor2025smolvla}.
At batch size one inside a control loop, every re-plan waits for the full model.
Efficient-VLA work reduces this cost with smaller backbones, fewer tokens or layers, cheaper action decoding, asynchronous execution or faster inference systems (\cref{sec:study}), but a saving can change closed-loop behaviour: an ONNX export of the SmolVLA checkpoint used here cut median latency by 40\% and, through truncated instructions, LIBERO-Spatial success from 70\% to 41\%~\cite{islam2026onnx}.

This report studies SmolVLA~\cite{shukor2025smolvla} on LIBERO-Spatial~\cite{liu2023libero} with a Tesla T4, a GPU without bfloat16 tensor cores, in a training-free setting: weights, architecture and protocol stay fixed, and only the execution changes.
It surveys efficient VLAs and diffusion versus flow-matching action heads (\cref{sec:study}, with an 18-paper literature matrix), reproduces the released checkpoint (\cref{sec:reproduce}), analyses its strengths, limitations and bottlenecks (\cref{sec:analysis}), and tests two hypotheses on identical episodes: re-planning less often, and re-planning more cheaply (\cref{sec:improve}).
The levers that make re-planning cheaper are known~\cite{ma2025realtime,tang2026coda}; the contribution is a measured account of why each helps on this hardware and a paired closed-loop test of whether success is preserved.
